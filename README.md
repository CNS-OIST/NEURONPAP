# Welcome to the NEURON model of Perisynaptic Astrocyitc Processes(PAPs)
This model tries to explore the electrophysiolgical properties at PAPs.

The model is based on the models below.
- Savtchenko LP, Bard L, Jensen TP, Reynolds JP, Kraev I, Medvedev N, Stewart MG, Henneberger C, Rusakov DA (2018) Disentangling astroglial physiology with a realistic cell model in silico. [Nat Commun](http://dx.doi.org/10.1038/s41467-018-05896-w) 9:3554 [ModelDB](https://senselab.med.yale.edu/ModelDB/ShowModel?model=243508#tabs-1)

- Moradi K, Moradi K, Ganjkhani M, Hajihasani M, Gharibzadeh S, Kaka G (2013) A fast model of voltage-dependent NMDA receptors. [J Comput Neurosci](http://dx.doi.org/10.1007/s10827-012-0434-4) 34:521-31 [ModelDB](https://senselab.med.yale.edu/ModelDB/ShowModel?model=145836#tabs-1)

- Janiac

- The Kir channel model is a modification to the model used by Savtchenko LP et al. that was fine tuned single channel conductance with a newly fitted time constant.
